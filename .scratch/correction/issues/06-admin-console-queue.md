# 06 · 管理后台「纠错队列」卡片

Status: resolved

## 任务

`frontend/src/App.tsx` 与 `api.ts` 新增纠错队列区块（放在「知识库体检」与「知识管理」之间）。

- 列表默认拉 pending，可切到全部。
- 每条折叠显示：问题 + 用户说明 + 时间；展开显示回答全文快照、来源标签、
  以及**关联知识正文的内联编辑框**（复用现有 `PATCH /admin/docs/{id}` 与删除逻辑）。
- `doc_ids` 为空时显示「无关联知识（可能是库里缺）」，并提示可走 URL 摄入补录。
- 底部「标记已处理」按钮 + 处理备注输入，提交后该条从 pending 列表移除。
- 视觉沿用现有 slate 暗色卡片风格。

## 验收

- 待处理数量在卡片标题上可见。
- 内联改完知识后，知识管理区刷新能看到同一条已更新（且 changelog 有记录）。
- 标记已处理后列表即时更新。
