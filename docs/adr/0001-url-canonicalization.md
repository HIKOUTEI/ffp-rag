# URL 规范化用于判重，公众号只保留 `__biz/mid/idx/sn`

为实现「相同 URL 不重复录入」，我们以**规范化 URL** 而非原始链接作为判重 key：
统一 scheme/host 大小写、去 `#` 片段、剔除追踪参数黑名单（`chksm/scene/sn/srcid/from/utm_*` 等）。
对微信公众号 `mp.weixin.qq.com` 额外特判——只保留能唯一标识文章的 `__biz/mid/idx/sn`，
其余参数全部丢弃。

## 为什么给公众号开小灶

公众号是本项目主力来源，其分享链接几乎必带随机追踪参数，同一篇文章两次拿到的链接
往往不同。仅靠通用黑名单不足以稳定折叠这些变体，故用白名单参数把归一化做得更狠。

## 考虑过但没采用

完整方案（从 `__biz+mid+idx` 反推文章身份、处理短链跳转）能更精确，但需要专门解析与
维护，收益不足。白名单特判是「够用且便宜」的折中。
